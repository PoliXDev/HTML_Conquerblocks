## Description

This project is a frontend development for the Conquerblocks academy that demonstrates advanced CSS techniques and skills, responsive design, and semantic HTML. The site is designed to professionally showcase the courses, instructors, and services of an academy specialized in technology training.

## Features

- **Responsive Design**: Fully adaptable structure that works perfectly on desktop, tablet, and mobile devices
- **Modern UI Components**: Clean and elegant design with special attention to typography, spacing, and visual hierarchy
- **Interactive Elements**: Hover effects and smooth transitions
- **Hero Section with Video**: Impactful main section with video playback
- **Course Cards**: Presentation of featured courses with modern design
- **Instructors Section**: Showcase of the teaching team with their specialties
- **Mobile Navigation**: Custom menu for small screens
- **Semantic HTML**: Properly structured HTML with appropriate semantic elements for better accessibility and SEO
- **Optimized Media**: Properly sized and optimized images and videos for better performance

## Technologies Used

- HTML5
- CSS3 (with custom properties/variables)
- SCSS/Sass for styles
- JavaScript
- Mobile-first responsive design
- CSS Flexbox for layouts
- CSS Grid for specific sections
- CSS Transitions for animations
- Vite as build tool

## Main Sections

- Home page with promotional video
- Course catalog
- Details of each training program
- "About Us" section
- Login/registration system
- Blog with industry news
- Legal information and contact
